# ListingLift

ListingLift is an AI-assisted product photo cleanup and ecommerce image fulfillment platform.

Core offer: upload messy product photos and receive organized, seller-review-ready image packs for ecommerce and marketplace use.

This repository seed is designed for Codex to stitch into a real repository and complete phase-by-phase.

## Implementation status

- Current roadmap phase: Phase 0 — Repository Initialization
- This package includes repo scaffolding, code skeletons, typed contracts, Prisma schema draft, tests, docs, and Codex handoff instructions.
- It does **not** claim that dependencies are installed or that tests have been run in the target repo.

## Safety rules

- Mock adapters are enabled by default.
- Real integrations are disabled by default.
- No secrets are included.
- Final client delivery must remain hidden until admin approval.
- Marketplace output language must be seller-review safe and must not guarantee marketplace approval.
