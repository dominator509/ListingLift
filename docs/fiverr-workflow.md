# fiverr-workflow.md

Fiverr workflow is manual-first. Do not scrape private pages, store Fiverr passwords, or automate messaging outside Fiverr-approved methods. Normalize all Fiverr orders into ListingLift external orders and jobs while preserving source attribution.

## Phase 20 MVP Workflow

1. Admin manually creates job from Fiverr order.
2. Admin uploads client files or downloaded ZIP through existing secure upload/admin upload flow.
3. Admin selects a Fiverr gig/package preset.
4. ListingLift processes images using the same processing, QC, approval, revision, and delivery gates as all other channels.
5. Admin downloads final ZIP or uses the approved delivery archive.
6. Admin delivers through Fiverr and records completion in ListingLift.

## Scalable Workflow

Where approved API or partner access exists later, ListingLift may support:

- Fiverr order import.
- Buyer/order capture.
- Package mapping.
- Deadline sync.
- Fiverr delivery ZIP generation.
- Revision status tracking.
- Revenue by gig.
- Fiverr delivery templates.

## Safety Requirements

- Manual fallback is mandatory.
- No private page scraping.
- No marketplace password storage.
- No unauthorized buyer-message automation.
- Keep final delivery inside Fiverr when required.
- Use external links only where Fiverr allows them.
- Do not guarantee Amazon/Etsy/eBay/TikTok/Shopify approval, ranking, sales, conversions, or ad performance.
