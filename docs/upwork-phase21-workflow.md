# Phase 21 — Upwork Workflow

This phase expands Upwork from a generic sales-channel adapter into a dedicated manual/semi-automated workflow for higher-value contracts and retainers.

## Core Data

- Upwork contract ID
- Client name/company
- Contract title
- Contract type: fixed price, hourly, retainer, agency subcontract, bulk catalog
- Milestone title/status
- Due date
- Billed amount or hourly estimate
- Package mapping
- Revision status
- Source URL
- Revenue attribution

## Outputs

- Internal client draft
- External order draft
- ListingLift job draft
- Upload-link plan
- Proposal/message template
- Delivery template
- Retainer reminder
- Revision status plan
- Safety check result

## Safety

The baseline must remain manual-first. Do not automate Upwork messaging, proposals, or delivery unless a clearly approved integration path exists.
