# taskrabbit-workflow.md

Taskrabbit workflow is manual-first. Use manual order entry, upload links where allowed, audited status corrections, local-service context, and conversion tracking from Taskrabbit tasks to direct ListingLift clients only when platform rules and customer consent allow it.

## Supported use cases

- Product photo cleanup support
- Marketplace listing setup help
- Restaurant menu image cleanup
- Real estate listing visual organization
- Facebook Marketplace/eBay listing image preparation
- Small business ecommerce setup support

## Required fields

- Taskrabbit task ID
- Customer name or redacted customer reference
- Business/store name when provided
- Task category
- Appointment/deadline
- Task value and currency
- Source URL if safe/allowed
- Internal client ID
- Internal job ID
- Upload status
- Fulfillment status
- Direct retainer conversion status

## Manual fallback

Manual fallback is core. If Taskrabbit integration or platform behavior prevents automation, the operator must be able to manually enter the task, upload files, mark delivery, update conversion status, and audit the action.
