# Other Sales Channel Workflows

Phase 23 adds manual-first workflow coverage for channels that are useful for acquiring ListingLift clients but should not be treated as direct automated integrations by default.

## Core Workflow

1. Admin captures lead/order/source details manually.
2. System normalizes the source into a ListingLift external order draft.
3. Admin creates or matches the client.
4. System creates a job draft and optional upload-token plan.
5. Operator sends a proposal, follow-up, upload link, delivery message, or retainer prompt manually.
6. Revenue is attributed by source.
7. Delivery remains gated by the approval, QC, and delivery-token systems.

## Safety Rules

Do not scrape private pages, store platform passwords, automate DMs/proposals/comments/replies/bookings, or move customers off-platform in violation of source rules. External upload/download links are allowed only where the source context permits them.
