# USER_GUIDE.md

## Client flow

1. Choose a package.
2. Submit intake details.
3. Upload product photos or ZIP.
4. Wait for processing and review.
5. View approved preview/delivery when available.
6. Request revisions if included.
7. Download final ZIP after approval.

All outputs are platform-ready drafts and should be reviewed by the seller before publishing.

## Phase 33 Client Dashboard

Clients can use the dashboard to track jobs, upload files, review approved previews, download approved delivery ZIPs, request revisions, view billing/credits, and consider optional upgrade recommendations. Final downloads remain hidden until admin approval and delivery release.
